# Platform Agregator Jurnal — Prototype

Prototype UI untuk platform agregator jurnal dari Scopus, Sinta, DOAJ, Google Scholar, dan jurnal gratis.

## Tampilan Utama

- **Landing Page**: `http://localhost:3000` — hero, fitur, dan ringkasan sumber dalam gaya Travel App Landing Page.
- **Workspace**: `http://localhost:3000/app` — 3-Pane Academic Workspace dengan sidebar, pencarian, dan detail jurnal.

## Menjalankan

```bash
cd D:\vessel2\frontend-prototype
npm install
npm run dev
```

Buka http://localhost:3000

## Fitur Prototype

- Pencarian multi-sumber: Scopus, Sinta, DOAJ, Google Scholar.
- Jurnal gratis / Open Access.
- Folder & reading list.
- Citation tools: APA, IEEE, Chicago, Harvard, unduh `.BIB`.
- AI summary panel.
- 3-Pane workspace.
- Dark mode.
